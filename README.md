# gym-tracker

Aplicación web personal para registrar entrenamientos de gimnasio y consultar la evolución a lo largo del tiempo.

## Objetivo

Disponer de una herramienta accesible desde iPhone (Safari) y MacBook para:

- Registrar series con **ejercicio** (de un listado predefinido), **peso** y **repeticiones**.
- Consultar el historial por día, ejercicio o grupo muscular.
- Ver gráficos de progresión (peso máximo, volumen, etc.).

## Stack (por decidir)

- **Frontend:** web app responsive (probablemente HTML/CSS/JS o un framework ligero).
- **Persistencia:** Google Sheets o base de datos ligera (SQLite / archivo JSON).
- **Despliegue:** TBD (acceso local, GitHub Pages, o un host gratuito).
